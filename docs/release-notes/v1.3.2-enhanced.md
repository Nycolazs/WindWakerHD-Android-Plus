# v1.3.2 Enhanced — Up to date with the original Android port (v0.9)

This version brings in everything from the latest version of the Android port this fork comes from
(GreenNaugahyde's v0.8 and v0.9), merged with this fork's own features.

**The APK contains no game files, no game code and no keys.** It installs over any earlier version
and keeps your saves and settings. At its first start the game code is prepared again (a few
minutes, once), and shaders are compiled again as you play.

## Performance

- **Faster game thread (about −30%)**: the recompiled game code keeps the console's registers in
  local variables instead of memory.
- **Faster render thread (about −40%)**: quicker shader, pipeline and texture lookups, and
  `GX2DrawDone` waits for the GPU only when it really has to.
- **Faster audio**: the two heaviest sound mixing loops run as native code, with the same output
  (game audio thread 15% → 10% of a core on a Mi 9).
- **Big cores**: on devices without a performance hint session (Android 12 and older, or devices
  that refuse one), the game and render threads stay on the big cores. The *CPU cores* setting
  still has the last word.

## Frame rate

- **60 fps keeps the game at full speed**: where an in-between frame doesn't fit in time it is left
  out, so the game never slows down. This replaces *60 fps (adaptive)*; if you had it selected, you
  now get 60 fps.
- **New: 120 fps** on 120 Hz screens (frame interpolation, 3 in-between frames per game step).
- **40 fps** on 120 Hz screens stays as its own option and works as before.
- Better interpolation from the original project: cloth, the night sky's stars and the HD UI
  screens.

*Options → Graphics → Frame rate*: 30, 60 and True 60 everywhere; 120 and 40 fps on 120 Hz
screens.

## Fixes

- **Rito mail sorting game**: the letter card is no longer black.
- **Grandma's shield** with fast scene changes on.
- **Light flashes in Beetle's shop** with Turnip drivers. There is a new *Command recording thread*
  setting (*Options → Graphics*), which applies at the next start.
- **Crashes on some MediaTek devices** (Dimensity 8350): the game code is no longer built with SVE.
- **Arithmetic edge cases** in the game code (integer overflow the game relies on) are handled
  exactly as on the console.
- **Crash logs** are also offered when the app fails before the game starts, or exits in a way the
  crash handler can't catch.

Everything else is as in v1.3.1: see the earlier notes.

## Installing

Install the APK over any earlier version. Requirements: Android 11 or newer, 64-bit ARM,
Vulkan 1.1, about 2 GB of free storage and memory.

If the app crashes, share the log it offers at the next start (or from *About*) with your report.
